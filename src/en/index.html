Installation help

Blocked when opening it?
Let's fix that in a minute.

Windows and macOS sometimes show a warning for independent software. That's normal, and it takes two clicks to get past it. Follow the guide for your system.

✓

neoSlice is safe. These warnings don't mean there's a virus: they appear because neoSlice is a recent piece of software, published by an independent studio and not signed by a major publisher. The installation files are published on GitHub, the go-to platform for developers.

1"neoSlice_Setup_Windows.exe isn't commonly downloaded" (while downloading)⌄

This window appears during the download, before installation even starts. The catch is that the only clearly visible button is Delete: if you click it, the file is erased and nothing gets installed.

  1. Don't click Delete. Click the small arrow just to the right of the word Delete.
  2. Choose Keep in the menu that opens.
  3. If Windows insists with a Show more link, click it, then Keep anyway.
  4. The file finishes downloading. You can open it: the next step is waiting for you.

Why? Windows looks at how many people have already downloaded this file. neoSlice is a recent piece of software from an independent studio: the count is low, so the warning appears. It says nothing about what the file contains.

2"Windows protected your PC" (blue SmartScreen screen)⌄

This is the most common warning. It doesn't block the file, it just asks you to confirm.

  1. Click More info (the small link under the text).
  2. A Run anyway button appears at the bottom. Click it.
  3. Installation starts normally.
3"MSVCP140.dll" or "VCRUNTIME140.dll" is missing⌄

These files are part of a Microsoft component most PCs already have. If it's missing, install it for free:

  1. Download Microsoft's Visual C++ Redistributable (x64): aka.ms/vs/17/release/vc_redist.x64.exe
  2. Run it, accept, let it install (10 seconds).
  3. Restart neoSlice. The message is gone.
4The download stops, or I get a ".crdownload" file⌄

A .crdownload file (or .partial in Edge) is an unfinished download. The browser interrupted or paused the save.

  1. Open the browser's downloads (Ctrl + J).
  2. If the file is paused, click Resume. If it's flagged as dangerous, click Keep, then Keep anyway.
  3. Wait until the extension is back to .exe (Windows) or .zip (Mac) before opening it.

Tip: if it's still stuck, restart the download from the official link, or try another browser.

5My antivirus quarantines or deletes the file⌄

Some antivirus programs are overzealous with new independent software (a "false positive"). You can safely allow neoSlice.

  1. Open your antivirus and go to Quarantine or Threat history.
  2. Select neoSlice and choose Restore, then Allow (or "Add an exclusion").
  3. Run the installation again.

In Windows Defender: Windows Security → Virus & threat protection → Protection history → Actions → Allow.

6neoSlice installs but won't open, or closes right away⌄
  1. Fully close neoSlice if it was already running (icon in the taskbar).
  2. Right-click → Run as administrator the first time.
  3. The first launch prepares the 3D display: give it a few seconds.
  4. Still nothing? Reinstall the latest version from the official link, then restart the PC.

Windows 10 and 11 (64-bit).

1"neoSlice can't be opened" or "Apple could not verify…"⌄

This is Gatekeeper, macOS security. You only need to unlock it once, and this method works on every version of macOS:

  1. Double-click neoSlice in the Applications folder. The warning appears: close it with Done or OK.
  2. Open System Settings → Privacy & Security.
  3. Scroll down to the Security section: a message mentions neoSlice with an Open Anyway button.
  4. Click it, then confirm with your password or Touch ID.
  5. It's remembered: from then on, neoSlice opens with a normal double-click.
2Shortcut on macOS 12 to 14 (Monterey, Ventura, Sonoma)⌄

On these versions, a right-click gets you there faster. Apple removed it in macOS 15 Sequoia: use step 1 instead.

  1. In the Applications folder, right-click (or Ctrl-click) neoSlice.
  2. Choose Open from the menu.
  3. The same warning comes back, but this time with an Open button. Click it.
3"neoSlice is damaged and can't be opened"⌄

This misleading message comes from the quarantine flag macOS puts on files downloaded from the internet. The app isn't actually damaged. Two solutions:

Simple: delete neoSlice, download the .zip again, unzip it, and drag neoSlice into Applications before following step 1.

If it persists, open the Terminal app and paste this line (it simply removes the quarantine flag):

xattr -dr com.apple.quarantine /Applications/neoSlice.app

Press Return, then open neoSlice normally.

4The .zip won't unzip, or the app stays as ".download"⌄
  1. Check that the download is finished: a .download file is still in progress.
  2. Double-click the .zip: macOS creates the app right next to it.
  3. Drag neoSlice into your Applications folder, then launch it from there (on first launch, follow step 1).
