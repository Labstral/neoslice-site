Aide à l'installation

Un blocage à l'ouverture ?
On règle ça en une minute.

Windows et macOS affichent parfois une alerte pour les logiciels indépendants. C'est normal, et ça se contourne en deux clics. Suivez le guide selon votre système.

✓

neoSlice est sain. Ces avertissements n'indiquent pas un virus : ils apparaissent parce que neoSlice est un logiciel récent, édité par un studio indépendant et non signé par un grand éditeur. Les fichiers d'installation sont publiés sur GitHub, la plateforme de référence des développeurs.

1« neoSlice_Setup_Windows.exe n’est pas fréquemment téléchargé » (au téléchargement)⌄

Cette fenêtre apparaît pendant le téléchargement, avant même l’installation. Le piège est que le seul bouton bien visible s’appelle Supprimer : si vous cliquez dessus, le fichier est effacé et rien ne s’installe.

  1. Ne cliquez pas sur Supprimer. Cliquez sur la petite flèche juste à droite du mot Supprimer.
  2. Choisissez Conserver dans le menu qui s’ouvre.
  3. Si Windows insiste avec un lien Afficher plus, cliquez dessus, puis sur Conserver quand même.
  4. Le fichier descend entièrement. Vous pouvez l’ouvrir : l’étape suivante vous attend.

Pourquoi ? Windows regarde combien de personnes ont déjà téléchargé ce fichier. neoSlice est un logiciel récent édité par un studio indépendant : le compteur est bas, donc l’alerte apparaît. Elle ne dit rien du contenu du fichier.

2« Windows a protégé votre ordinateur » (écran bleu SmartScreen)⌄

C'est l'alerte la plus courante. Elle ne bloque pas le fichier, elle demande juste une confirmation.

  1. Cliquez sur Informations complémentaires (le petit lien sous le texte).
  2. Un bouton Exécuter quand même apparaît en bas. Cliquez dessus.
  3. L'installation démarre normalement.
3Il manque « MSVCP140.dll » ou « VCRUNTIME140.dll »⌄

Ces fichiers font partie d'un composant Microsoft que la plupart des PC possèdent déjà. S'il manque, installez-le gratuitement :

  1. Téléchargez le Visual C++ Redistributable (x64) de Microsoft : aka.ms/vs/17/release/vc_redist.x64.exe
  2. Lancez-le, acceptez, laissez-le s'installer (10 secondes).
  3. Redémarrez neoSlice. Le message disparaît.
4Le téléchargement s'arrête, ou j'obtiens un fichier « .crdownload »⌄

Un fichier .crdownload (ou .partial sur Edge) est un téléchargement non terminé. Le navigateur a interrompu ou mis en pause l'enregistrement.

  1. Ouvrez les téléchargements du navigateur (Ctrl + J).
  2. Si le fichier est en pause, cliquez sur Reprendre. S'il est marqué comme dangereux, cliquez sur Conserver puis Conserver quand même.
  3. Attendez que l'extension redevienne .exe (Windows) ou .zip (Mac) avant de l'ouvrir.

Astuce : si ça bloque toujours, relancez le téléchargement depuis le lien officiel, ou essayez un autre navigateur.

5Mon antivirus met le fichier en quarantaine ou le supprime⌄

Certains antivirus sont zélés avec les nouveaux logiciels indépendants (« faux positif »). Vous pouvez autoriser neoSlice en toute confiance.

  1. Ouvrez votre antivirus, allez dans Quarantaine ou Historique des menaces.
  2. Sélectionnez neoSlice et choisissez Restaurer puis Autoriser (ou « Ajouter une exclusion »).
  3. Relancez l'installation.

Sous Windows Defender : Sécurité Windows → Protection contre les virus → Historique de protection → Actions → Autoriser.

6neoSlice s'installe mais ne s'ouvre pas / se ferme aussitôt⌄
  1. Fermez complètement neoSlice s'il tournait déjà (icône dans la barre des tâches).
  2. Faites un clic droit → Exécuter en tant qu'administrateur une première fois.
  3. Le premier lancement prépare l'affichage 3D : laissez-lui quelques secondes.
  4. Toujours rien ? Réinstallez la dernière version depuis le lien officiel, puis redémarrez le PC.

1« neoSlice ne peut pas être ouvert » ou « Apple n'a pas pu vérifier… »⌄

C'est Gatekeeper, la sécurité de macOS. Il se débloque une seule fois, et cette méthode marche sur toutes les versions de macOS :

  1. Double-cliquez sur neoSlice dans le dossier Applications. L'alerte s'affiche : fermez-la avec Terminé ou OK.
  2. Ouvrez Réglages Système → Confidentialité et sécurité.
  3. Descendez jusqu'à la section Sécurité : un message mentionne neoSlice avec un bouton Ouvrir quand même.
  4. Cliquez dessus, puis confirmez avec votre mot de passe ou Touch ID.
  5. C'est mémorisé : les prochains lancements se font normalement d'un double-clic.
2Raccourci sur macOS 12 à 14 (Monterey, Ventura, Sonoma)⌄

Sur ces versions, le clic droit permet d'aller plus vite. Depuis macOS 15 Sequoia, Apple l'a retiré : suivez alors l'étape 1.

  1. Dans le dossier Applications, faites un clic droit (ou Ctrl + clic) sur neoSlice.
  2. Choisissez Ouvrir dans le menu.
  3. La même alerte revient, mais cette fois avec un bouton Ouvrir. Cliquez dessus.
3« neoSlice est endommagé et ne peut pas être ouvert »⌄

Ce message trompeur vient de la quarantaine posée par macOS sur les fichiers venus d'Internet. L'application n'est pas réellement endommagée. Deux solutions :

Simple : supprimez neoSlice, puis retéléchargez le .zip, décompressez-le, et glissez neoSlice dans Applications avant de suivre l'étape 1.

Si ça persiste, ouvrez l'app Terminal et collez cette ligne (elle retire simplement l'étiquette de quarantaine) :

xattr -dr com.apple.quarantine /Applications/neoSlice.app

Appuyez sur Entrée, puis ouvrez neoSlice normalement.

4Le .zip ne se décompresse pas, ou l'app reste en « .download »⌄
  1. Vérifiez que le téléchargement est terminé : un fichier en .download est encore en cours.
  2. Ouvrez le .zip par un double-clic : macOS crée l'application à côté.
  3. Glissez neoSlice dans votre dossier Applications, puis lancez-le depuis là (au premier lancement, suivez l'étape 1).
